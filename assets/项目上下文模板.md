# 项目交付配置

有本地项目目录时使用文件名 `项目上下文.md`，放在被分析项目根目录；纯远端项目可将内容作为已授权项目页面或父项中的“项目上下文”章节。配置后续原型设计、交互与设计规范、任务拆解和文档维护的目标、工具、规则与关联方式。已知项直接填入，未知项按需补充；不保存密码或令牌。

## 项目

| 配置 | 值 |
|---|---|
| 项目名称／代号 | 未确认 |
| 项目根目录／代码仓库 | 未确认；纯远端且无本地目录／仓库时说明实际情况 |
| 配置维护位置与路径基准 | 本地文件路径或远端页面／父项 URL、ID 及章节；本地相对路径的基准目录 |

## 原型与设计

| 配置 | 值 |
|---|---|
| 原型设计工具 | 未确认；填写实际工具及工作区，例如 Figma、即时设计、Axure、Miro 或本地 HTML；没有时说明采用的本地方式 |
| 正式原型位置 | 未确认；填写工具中的文件／页面链接或 ID；本地原型填写可编辑源路径 |
| 预览与导出方式 | 未确认；填写可访问预览、运行入口或导出位置，截图不能代替可编辑源 |
| 设计规范与组件库 | 未确认；填写已有规范、设计系统或组件库的链接／路径；没有时写“暂无，待本阶段收敛” |
| 原型操作权限与范围 | 未确认；记录本轮允许查看、编辑、发布或整理的范围，不保存凭据 |
| 原型素材与样例数据 | 未确认；填写可复用素材、样例账号或数据位置；不要使用未授权真实数据 |

## 任务管理系统

| 配置 | 值 |
|---|---|
| 目标系统 | 未确认；例如 Jira；不用远端时写“本地按故事维护” |
| 实例地址与项目 | 未确认；例如实例 URL 与项目 key |
| 任务类型与层级 | 未确认；按目标项目实际配置填写，不预设 Epic／Story／Sub-task |
| 默认关联父项 | 未确认；按需求选择或明确无默认父项 |
| 任务内容约定 | 故事的本次目标、详细行为、验收条件及可执行研发测试任务；任务包含范围、输入输出、依赖、完成判据与证据，测试含数据／环境、步骤和预期 |
| 负责人、优先级、版本等默认值 | 未确认；没有约定不推测 |
| 执行约定 | 默认在用户要求创建／同步任务时执行；如用户已明确授权自动落地，记录适用范围和依据 |
| 已有任务关联记录位置 | 未确认；保存需求／场景／故事 ID、验收条件与研发测试任务 key／URL 的对应关系 |

## 需求文档维护

| 配置 | 值 |
|---|---|
| 正式维护位置 | 未确认；本地目录／Notion／Confluence／其他，选择实际主位置 |
| 本地目标 | 未确认；使用本地时填写目录或已有文件 |
| Notion 目标 | 未确认；使用时填写工作区及父页面／数据库链接或 ID |
| Confluence 目标 | 未确认；使用时填写站点、space key 和父页面／已有页面链接或 ID |
| 文档组织方式 | 主文先整体后局部，专题及必要子专题沿用同一原则；需求、模型、架构、原型、交互与设计规范按维护责任归属；本地维护故事时每故事独立文档，总览保留索引和批次；任务系统维护故事时记录实际链接，不重复正文 |
| 已有文档与维护范围 | 未确认；指定已有文档及可更新章节，避免每次重新创建 |
| 保存方式 | 默认更新关联的已有文档；无关联时按目标组织方式新建 |
| 执行约定 | 记录用户是否要求阶段结果直接写回正式位置，或先保留草稿；仅填写地址不视为发布授权 |
| 正式正文根目录／页面 | 本地未约定时为 docs/project-analysis/，保存当前需求、模型、设计及本地故事；正式维护的草拟规范可原位迭代 |
| 辅助材料根目录／页面组 | 本地未约定时为 docs/project-analysis-support/；与正式正文分区 |
| 来源／决策／变更 | 辅助根下“来源/”“决策/”“变更/”或已有等价位置 |
| 验证／实验位置 | 完整验证报告在辅助根“验证/”；实验代码与运行环境沿用项目 experiments/ 或已约定位置，不复制证据 |
| 附件位置 | 辅助根“附件/”或远端独立附件区域，保存可编辑图源、图片及其他附属产物 |
| 临时草稿与清理 | 辅助根“草稿/”；已整合且无保留价值的中间材料在维护范围内清理，必要证据分类保留 |
| 必要归档位置 | 版本历史优先；确需独立保留时使用辅助根“归档/”，不默认复制整套旧正文 |
| 项目概览位置 | 正式正文根下项目概览.md，或已有等价入口 |
| 交接位置 | 辅助根下交接/交接记录.md，或独立交接页；不混入组件设计正文／目录 |

只保留选中平台的配置行。不同时维护多套正文，除非明确要求并约定同步方向。

## 任务与文档关联

| 配置 | 值 |
|---|---|
| 需求正文的正式来源 | 上面指定的正式维护位置；有例外则填写 |
| 任务执行状态的正式来源 | 上面指定的任务管理系统；有例外则填写 |
| 故事／AC／任务正文的正式来源 | 任务系统或本地故事文档，选择唯一主位置；本地默认 docs/project-analysis/stories/用户故事-编号-主题.md |
| 原型与设计规范的正式来源 | 上面“原型与设计”中的工具、文件／页面、可编辑源、预览及规范位置 |
| 关联方式 | 研发测试任务引用需求文档、故事 ID 及验收条件；文档记录相关任务 key／URL 和结果证据 |
| 草稿与远端版本的关系 | 未确认；例如远端为正式版本、本地仅作待发布草稿 |

配置依据：填写用户说明或已有项目约定。
最近核实日期：未确认。
待补充信息：按当前动作需要列出。
