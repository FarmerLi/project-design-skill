# 目标与问题澄清

## 阶段目标与输入

将想法或方案诉求转化为可供价值与可行性评估的问题定义：说明谁在什么情境下遇到什么问题、希望发生什么变化、如何观察变化，以及当前分析边界和已知约束。本阶段明确价值判断的对象与依据，不负责证明收益成立或确定最终方案。

最低输入为想法、问题或目标描述，可来自对话或已有材料。先读同包的 [交接契约](../shared/working-contract.md)，只加载已有项目概览及本轮有关材料；缺少概览不阻塞开始，不要求补齐前序文件。

## 工作方法

先根据已有信息给出简短理解和草稿，再按以下顺序补足缺口；已有答案直接复用，不把步骤变成逐项访谈问卷。

1. **整理输入与来源。** 分开问题、期望效果、拟采用的方案和约束，标明事实、假设及待决项。识别本次工作的触发原因、不改变的后果与已有明确决定；“做一个平台”本身不足以定义问题。
2. **还原代表性场景。** 说明谁在什么情境下完成什么任务、当前如何处理、遇到什么问题及已知成本或损失，再描述期望结果。区分目标用户、业务决策人和操作角色；同一人可承担多个角色，无需虚构复杂组织。
3. **提炼目标与成功信号。** 将拟建功能还原为预期变化，说明通过什么观察、记录或反馈判断改善。缺少基线时提出测量方式；识别相互冲突的目标，复用已有优先级，尚无取舍时列出冲突、影响及需要业务决策人决定的事项，不替用户猜测。
4. **划定边界与约束。** 从上述问题和场景中明确本轮纳入与暂不纳入的用户、问题或场景。记录已知期限、预算、外部依赖等约束的来源与适用范围，分开硬约束、偏好及候选方案。初步范围用于限定分析对象，不作为首期功能或交付承诺。
5. **收敛结论与缺口。** 汇总问题定义、成功信号和边界，按下方完成标准检查。对剩余未知说明影响、补证或决策方式、是否阻塞价值判断，以及最迟在哪一步解决；只追问影响当前结论的关键缺口，通常每轮 1～3 个问题。

不要求用户回答尚无条件知道的问题。能整理的先整理，缺少证据时保留条件性结论，并给出验证入口；只推进不依赖阻塞项的部分。

## 本阶段约束

- 不提前选技术栈、不输出完整功能清单，不把功能设想默认纳入范围。
- 用户明确要求必须采用的方案记为已定约束；举例、设想或偏好保留为候选。无法判断且影响当前结论时再追问，不擅自删除方案或重开明确决定。若已定约束与目标冲突，说明冲突并交回取舍，不静默放宽任何一方。
- 成功信号可以定性，但必须说明如何观察。区分已有指标、候选指标、待测基线和待定目标值；没有依据不生成数值阈值，提出测量方法不代表已经测量，澄清完成不代表收益已证明。
- 来源与确认状态分别记录，沿用公共交接契约；不把 AI 推测、用户沉默或文档整理完成当作业务确认。

## 最小产物

交付以下内容；需要保存时按项目配置维护，未配置正式位置时使用 `01-discovery.md`：

1. 问题与目标陈述、目标用户、代表性场景、当前做法及已知证据；
2. 预期变化与成功信号，含观察方式、已有指标及待补的基线或目标值；
3. 初步范围内／外、已定约束及其来源，另列偏好和候选方案；
4. 当前假设、目标冲突和待决问题，含影响、解决方式、阻塞范围及解决时点；
5. 阶段就绪结论、适用范围及依据。

持续分析或需要交接时，按项目配置维护最小概览、必要决策条目和交接；本地默认文件为 `project.md`、`decisions.md` 和 `handoff.md`。临时咨询无需建文件；已有章节可直接复用，不制造空表格。

## 完成标准与交接

以当前交付范围能否支持价值判断为准，按以下六项给出证据和结论；不以文件数量、问答轮数或所有未知清零作为完成标准。

| 检查项 | 本阶段达到什么程度即可 |
|---|---|
| 对象与问题 | 目标用户、发生情境、当前做法和问题可描述，已知事实与假设分开，分析对象无歧义 |
| 预期变化 | 能说明希望改善的结果，而非仅有拟建功能 |
| 成功信号 | 对当前目标有可观察的判断方式；基线和数值目标可待定，缺失时说明补充方式 |
| 初步边界 | 纳入与暂不纳入的用户、问题或场景可区分，未将候选功能变成交付承诺 |
| 约束与冲突 | 已知硬约束有来源和适用范围；影响当前价值判断的目标或约束冲突已有明确取舍 |
| 剩余未知 | 已说明影响、解决方式及解决时点，能解释为何不阻塞当前价值判断；未知不得隐含改变分析对象、目标或边界 |

与公共 [就绪检查](../shared/readiness.md) 的“目标 → 价值判断”保持一致，只检查本阶段适用项，不提前要求细化规则、设计或开发验收。

- **当前范围就绪：** 满足上述标准，可标为“可供下阶段使用”，携带不阻塞价值判断的待办。业务价值及可行性仍由后续评估验证。
- **存在关键阻塞：** 分析对象不明、只有抽象愿望而无观察方式，或关键冲突未解决时，交付条件性草稿，说明阻塞项与可继续部分；仅部分范围就绪时只对该范围作结论。
- **本轮结束：** 独立运行时，交付结果和必要缺口即可结束本轮；结束不等于阶段就绪。阶段就绪也不自动授权执行下一阶段，只有已获授权连续分析时才继续。
